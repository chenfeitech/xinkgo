# 人工验收

> 只能靠人眼、手感或真机验证的项登记在这里，不散落在设计文档里。
> 自动化覆盖不到的部分，由人在 macOS 上真的打开一个库走一遍。
>
> 验收方式：`make run`（或 `make dev`），用 `Open Vault…`（Cmd-O）选一个
> 装了 Markdown 笔记的文件夹，按下表逐条走。

## P0（R-1 ~ R-7）主链路

| # | 项 | 怎么验 | 预期 |
|---|---|---|---|
| A1 | 打开库 | `Open Vault…` 选一个文件夹 | 左栏立刻出现完整树（递归全量，非懒加载）；`.git` / `node_modules` / `target` / `.DS_Store` 不出现 |
| A2 | 隐藏文件开关 | 把配置 `basic.show_all_files` 改成 false 再开库 | 只剩"可编辑文本（含内容嗅探识别的无后缀文本）+ 图片" |
| A3 | 排序与图标 | 看树的顺序与行首符号 | 目录在前、同层按名称；目录 ▸、Markdown/文本 ·、图片 ▣、数据 {}、代码 </> |
| A4 | 新建 / 重命名 / 删除 / 移动 | 右键树上的一项，逐个用一遍 | 新建出现在选中项的旁边（目录内建目录）；重命名回车生效、Esc 取消、同名（忽略大小写）不动；删除有二次确认且不删库根；移动弹选目标文件夹 |
| A5 | 拖入导入 | 从 Finder 拖一个文件/文件夹到树上 | 复制进库，源还在；重名自动 `-1` |
| A6 | 粘贴进库 | 复制一张图片 / 一段文字，`Cmd-Shift-V` | 图片存成 `pasted.png`，文字存成新笔记并打开 |
| A7 | 多标签 | 依次点开三篇笔记，再点其中一篇 | 同一文件只有一个标签；重复点只激活，顺序不动、光标不动 |
| A8 | 自动保存 | 打字后停手 300ms | 文件落盘（`Cmd-S` 立即落盘）；标签上的 • 消失 |
| A9 | Markdown 工具栏 | 选中一段文字点"粗"；不选中点"代码块" | 选中被包裹；未选中插入一对标记且光标在中间；代码块光标停在两行 fence 之间 |
| A10 | 预览 | 打开一篇有图片、表格、代码块的笔记 | 图片（相对路径）显示；表格成形；代码块高亮 |
| A11 | 编辑区与预览区同源高亮 | 设置 `highlight.theme` 为 ocean / solarized，`basic.theme` 为 dark / light | 编辑区与预览区的代码颜色一起变，且跟随明暗 |
| A12 | 滚动同步 | 滚编辑区、滚预览区；`preview.sync_mode` 依次试 ratio / anchor / on_stop | 对端跟着走；拖动时不抖、不被拉回；改模式要重启 |
| A13 | 外部改文件 | 用别的编辑器改一篇已打开的笔记并保存 | 无未保存改动 → 自动载入新内容、光标不动；有未保存改动 → 保留并提示 |
| A14 | 外部增删文件 | 在库里新建 / 删掉一个文件 | 树自动更新；不在外部事件里重扫整棵树（不闪） |
| A15 | 重启恢复 | 打开几篇笔记后退出再启动 | 回到上次的库、同样的标签与顺序、同一个活动标签；退出前再写一次 |
| A16 | 三栏与分隔条 | 拖两条分隔线，改窗口大小 | 中间编辑区吃掉剩余宽度；拖完 400ms 写入 `layout.json`；重启后宽度还在 |
| A17 | 单实例 | 再启动一次应用 | 不新开进程，已开的窗口被唤到前台 |
| A18 | 键位覆盖 | 在 `config.json` 里把 `editor.keymap.Save` 改成 `cmd-shift-s` 后重启 | 菜单里 Save 显示新键位；冲突时保留靠前的动作 |


## P1（R-8）导航与面板

| # | 项 | 怎么验 | 预期 |
|---|---|---|---|
| B1 | 命令面板 | `Cmd-P`（菜单 File ▸ Go to Note…），打 `no` / `re` 等几个字母 | 按文件名模糊匹配，最贴的前 50 条在前，命中的字母加粗；上下键走、回车打开、Esc 或点外面关掉 |
| B2 | 索引 | 打开一个有双链与标签的库，等状态栏/日志 `index built` | 索引后台重建，不卡界面；打字时新写的 `[[..]]` 立刻被认识 |
| B3 | 全文搜索 | `Cmd-Shift-F`，打一个词，停手 | 停手约 200ms 后出结果（后台读盘，打字不卡）；每条是「文件名:行号 + 该行」，点击打开并把光标放到那一行 |
| B4 | 搜索边界 | 搜一个 >4MB 笔记里才有的词；搜一行很长的（如压缩 JSON） | 大文件跳过；长行截成「开头…结尾」 |
| B5 | 大纲 | 打开一篇有多级标题的笔记，点右侧 `◫` | 抽屉浮在编辑区右侧（不占布局宽度），标题按层级缩进，点一条跳到那一行；再点 `◫` 收起 |
| B6 | 反向链接 | 在另一篇笔记里写 `[[当前笔记名]]`，切回来点 `⇄` | 列出引用它的笔记与所在行，点一条跳到那个位置；自引不算 |
| B7 | 标签 | 在几篇笔记里写 `#想法` / `#Rust`，点 `＃` | 按数量降序；点一个标签列出带它的笔记，再点打开；大小写归一（`#Rust` 与 `#rust` 是一个） |
| B8 | 双链补全 | 在笔记里打 `[[` 再打几个字母 | 浮出候选（最多 30，模糊排序），点一个写入**相对库根的路径**；`]]` 一合上浮层就消失 |

## P2（R-10）AI

| # | 项 | 怎么验 | 期望 |
|---|---|---|---|
| D1 | 对话条开关 | 菜单 ▸ Ask AI（Cmd+Shift+A） | 编辑区下方出现对话条；再按一次只**隐藏**，历史保留 |
| D2 | 提问与流式回答 | 配好 Ollama / 兼容端点后，在输入框打字回车 | 用户提问立刻上屏；模型回答**逐字**浮现（Markdown 渲染），回答中按钮变 Stop |
| D3 | 未配置提示 | 不启用 AI 就提问 | 回答位置直接显示"还没有配置 AI：请到设置 · AI 里启用并选择模型"，不转圈等待 |
| D4 | 中止 | 回答途中点 Stop | 立即停止，已出来的字保留 |
| D5 | 思考与截断 | 用会 thinking 的模型提问 | 思维链以弱化小字显示、与正文分开；预算耗尽时正文下方提示"the model ran out of room" |
| D6 | 忘记 | 点 Forget | 该笔记的对话清空（只清这一篇的） |
| D7 | 断线重试与备用 | 停掉 Ollama 再提问 / 配 `fallback_model` | 一句话说清"网络不可用…检查地址是否正确"；配了备用模型时会去问备用 |
| D8 | 会话持久化 | 对话几轮后**退出应用再打开**，打开同一篇笔记；再点 Forget 后重启 | 重启后对话还在这篇笔记下（换一篇笔记没有）；Forget 后重启不再出现 |
| D9 | AI 修订评审 | 对话里让模型重写笔记，答完后点回答下方的 Look it over | 编辑区换成 diff 视图（原文 vs 模型稿）；悬停改动处有 Take/Revert；Take all / Send all back / Write it in / Away 四个按钮可用；Write it in 后回到编辑区且内容是剩下的那份 |
| D10 | 自动保存改动后仍稳 | 打字后立刻按 Cmd+S（与自动保存撞在一起） | 不崩、不写半截；`-race` 下不再报竞争 |
| D11 | 模型设置 | 设置 ▸ Settings ▸ AI：勾「Ask a model at all」，Add a model，Open 填 Address / Name / Speaks | 列表可增删；能力勾选后即"手动指定"（猜测不再覆盖）；点 Try it 出一行「It answers（xx ms），and it calls tools / but it calls no tools」；连不上时给一句能行动的话 |
| D12 | Skills | 在库里建 `.xink/skills/demo/SKILL.md`（`---` + `name:` + `description:` + `---` + 正文），再打开设置 | 设置 ▸ AI ▸ Skills 列出 demo（标「库内」），可勾选停用；库外 `~/Library/Application Support/Xinkgo/skills/<name>/` 的标「用户级」；同名时**库内优先** |
| D13 | Skills 入口 | Cmd+P 打 skill 名字 | 出现 `Skill · demo — <description>`；回车后对话条打开并显示 using demo，下一次提问会把 skill 正文一起发给模型；点 Put it down 后不再带 |
| D14 | Skills 坏文件 | 写一个缺 `description` 的 SKILL.md | 设置里列出路径 + 原因（「缺少 description」等），**不**静默消失 |
| D15 | 让它先查库 | 设置 ▸ AI 勾「Let it look through the vault」，先给模型点 Try it（把 `tools_enabled` 勾上），再问"库里有什么" | 对话里出现 `read_note → …` / `search_notes → …` 之类的小字，然后才是答案；走满步数时提示「走了太多步…」 |
| D16 | 工具只读 | 让模型去读 `../../` 外面的文件 | 回灌「不允许…」/「读不到…」，**不会**把库外文件内容发给模型 |
| D17 | 库级批量任务 | 菜单 ▸ Library tasks…：选「改标签」、填 `AI` → `人工智能`，点 Plan it | 列出每篇笔记的 `− 旧行 / + 新行` 预览，没有该标签的显示「跳过（没有 #AI）」；此时磁盘**未改**；点 Do the next batch 后磁盘才改，且标签面板里立刻变成新标签 |
| D18 | 改前快照 | 让模型改一篇笔记，Write it in 之后看 `~/Library/Application Support/Xinkgo/ai-history/` | 出现 `2026-…-<文件名>` 的旧版本；保留最近 200 份，多了删最旧 |
| D19 | 改后校验 | 让模型写一段带 `[[不存在的笔记]]` 的稿子，Write it in | 底部提示「written, but N 处要再看一眼：[双链] 第 N 行：…」，但**稿子照样写进去了**（校验只提示、不阻断） |

## 收尾（P1/P2 遗留）

| # | 项 | 怎么验 | 期望 |
|---|---|---|---|
| E1 | 面板显隐 | 设置 ▸ Window：勾掉 Show the file tree / Show the preview，再勾回来 | 面板消失；勾回来时**宽度跟关掉之前一样**（不是默认值）；重启后保持 |
| E2 | 快照取回 | 先让模型改一篇笔记（D18 会在 `ai-history/` 留下旧版本），再手工改动这篇，然后菜单 ▸ Snapshots… | 窗口按**新的在前**列出，每行是「文件名 + 时间 + 开头一行」，点 Put it back 后笔记回到旧版本；**当前内容先被存成一份新快照**（再点一次能回来）；若这篇笔记正开着，编辑区立刻显示取回的内容 |
| E3 | 模型克隆与排序 | 设置 ▸ AI：给某行改个 Address / 勾个能力，点 Clone，再点 ↑ / ↓ | 多出一行 `<原名>-copy`，**排在被复制那行的后面**，地址与能力都一样；改副本的 Address / 能力 / 上下文**不会**动到原行；↑ / ↓ 让它前后挪一位，第一行 ↑ 与最后一行 ↓ 是灰的；再 Clone 一次叫 `-copy2` |
| E4 | 模型的 Key 真的发出去 | 加一个 OpenAI 兼容模型（Speaks = open_ai_compatible），填 Address 与 Key，提问 | 请求带上 `Authorization: Bearer <key>`（配错的 key 得到的是 401，而不是"连不上/没鉴权"的含糊提示）；留空仍是匿名请求 |
| E5 | AI 旋钮 | 设置 ▸ AI ▸ Asking：改「How long an answer may take」「How often it is tried again」等，关掉设置再打开；再看 `config.json` | 数字**带得回来**（不是默认值）；`config.json` 里同步；`Answer in` 选 zh / en 后提问，模型的回答跟着换语言 |
| E6 | AI 动作 | 打开一篇笔记，Cmd+P 打 `Polish` 回车；再选中一段（只选中两三个词）打 `Condense` 回车 | 对话条自己打开并问出这句话；答完后**自动进入评审 diff**（不是直接写进笔记）；整篇时 diff 是整篇，有选区时 diff **只是那一段**，Write it in 后也只有那一段被改、前后文字不动 |
