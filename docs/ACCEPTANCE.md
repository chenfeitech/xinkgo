# 人工验收

> 只能靠人眼、手感或真机验证的项登记在这里，不散落在设计文档里。
> 自动化覆盖不到的部分，由人在 macOS 上真的打开一个库走一遍。
>
> 验收方式：`make run`（或 `make dev`），用 `Open Vault…`（Cmd-O）选一个
> 装了 Markdown 笔记的文件夹，按下表逐条走。

## P0（R-1 ~ R-7）主链路

| # | 项 | 怎么验 | 预期 |
|---|---|---|---|
| A1 | 打开库 | `Open Vault…` 选一个文件夹 | 左栏立刻出现完整树（递归全量，非懒加载）；`.git` / `node_modules` / `target` / `.DS_Store` 不出现 |
| A2 | 隐藏文件开关 | 把配置 `basic.show_all_files` 改成 false 再开库 | 只剩"可编辑文本 + 图片" |
| A3 | 排序与图标 | 看树的顺序与行首符号 | 目录在前、同层按名称；目录 ▸、Markdown ·、图片 ▣、数据 {}、代码 </> |
| A4 | 新建 / 重命名 / 删除 / 移动 | 右键树上的一项，逐个用一遍 | 新建出现在选中项的旁边（目录内建目录）；重命名回车生效、Esc 取消、同名（忽略大小写）不动；删除有二次确认且不删库根；移动弹选目标文件夹 |
| A5 | 拖入导入 | 从 Finder 拖一个文件/文件夹到树上 | 复制进库，源还在；重名自动 `-1` |
| A6 | 粘贴进库 | 复制一张图片 / 一段文字，`Cmd-Shift-V` | 图片存成 `pasted.png`，文字存成新笔记并打开 |
| A7 | 多标签 | 依次点开三篇笔记，再点其中一篇 | 同一文件只有一个标签；重复点只激活，顺序不动、光标不动 |
| A8 | 自动保存 | 打字后停手 300ms | 文件落盘（`Cmd-S` 立即落盘）；标签上的 • 消失 |
| A9 | Markdown 工具栏 | 选中一段文字点"粗"；不选中点"代码块" | 选中被包裹；未选中插入一对标记且光标在中间；代码块光标停在两行 fence 之间 |
| A10 | 预览 | 打开一篇有图片、表格、代码块的笔记 | 图片（相对路径）显示；表格成形；代码块高亮 |
| A11 | 编辑区与预览区同源高亮 | 设置 `highlight.theme` 为 ocean / solarized，`basic.theme` 为 dark / light | 编辑区与预览区的代码颜色一起变，且跟随明暗 |
| A12 | 滚动同步 | 滚编辑区、滚预览区；`preview.sync_mode` 依次试 ratio / anchor / on_stop | 对端跟着走；拖动时不抖、不被拉回；改模式要重启 |
| A13 | 外部改文件 | 用别的编辑器改一篇已打开的笔记并保存 | 无未保存改动 → 自动载入新内容、光标不动；有未保存改动 → 保留并提示 |
| A14 | 外部增删文件 | 在库里新建 / 删掉一个文件 | 树自动更新；不在外部事件里重扫整棵树（不闪） |
| A15 | 重启恢复 | 打开几篇笔记后退出再启动 | 回到上次的库、同样的标签与顺序、同一个活动标签；退出前再写一次 |
| A16 | 三栏与分隔条 | 拖两条分隔线，改窗口大小 | 中间编辑区吃掉剩余宽度；拖完 400ms 写入 `layout.json`；重启后宽度还在 |
| A17 | 单实例 | 再启动一次应用 | 不新开进程，已开的窗口被唤到前台 |
| A18 | 键位覆盖 | 在 `config.json` 里把 `editor.keymap.Save` 改成 `cmd-shift-s` 后重启 | 菜单里 Save 显示新键位；冲突时保留靠前的动作 |


## P1（R-8）导航与面板

| # | 项 | 怎么验 | 预期 |
|---|---|---|---|
| B1 | 命令面板 | `Cmd-P`（菜单 File ▸ Go to Note…），打 `no` / `re` 等几个字母 | 按文件名模糊匹配，最贴的前 50 条在前，命中的字母加粗；上下键走、回车打开、Esc 或点外面关掉 |
| B2 | 索引 | 打开一个有双链与标签的库，等状态栏/日志 `index built` | 索引后台重建，不卡界面；打字时新写的 `[[..]]` 立刻被认识 |
| B3 | 全文搜索 | `Cmd-Shift-F`，打一个词，停手 | 停手约 200ms 后出结果（后台读盘，打字不卡）；每条是「文件名:行号 + 该行」，点击打开并把光标放到那一行 |
| B4 | 搜索边界 | 搜一个 >4MB 笔记里才有的词；搜一行很长的（如压缩 JSON） | 大文件跳过；长行截成「开头…结尾」 |
| B5 | 大纲 | 打开一篇有多级标题的笔记，点右侧 `◫` | 抽屉浮在编辑区右侧（不占布局宽度），标题按层级缩进，点一条跳到那一行；再点 `◫` 收起 |
| B6 | 反向链接 | 在另一篇笔记里写 `[[当前笔记名]]`，切回来点 `⇄` | 列出引用它的笔记与所在行，点一条跳到那个位置；自引不算 |
| B7 | 标签 | 在几篇笔记里写 `#想法` / `#Rust`，点 `＃` | 按数量降序；点一个标签列出带它的笔记，再点打开；大小写归一（`#Rust` 与 `#rust` 是一个） |
| B8 | 双链补全 | 在笔记里打 `[[` 再打几个字母 | 浮出候选（最多 30，模糊排序），点一个写入**相对库根的路径**；`]]` 一合上浮层就消失 |

## 已自动化、不必人验的

库扫描与忽略规则、`fs` 的重名与跨设备移动、`note` 的原子写与外部变更取回、
`session` 的判重与 active 回落、`config` 的钳制与旧值迁移、`state` 的读写与迁移、
`keymap` 的冲突与清理、`sync` 的锚点换算与方向锁、`markdown` 的工具栏插入规则、
`highlight` 的三套主题取值：均有 Go 单元测试（`make test`）。
